Mapping My Network Path (Campus Network)

complete

Traced the path my laptop's traffic takes to reach the internet while connected to Algonquin College's WiFi, using only passive, read-only tools — since this is a shared network I don't administer, I deliberately avoided active scanning tools like nmap that probe other devices.

Ran ipconfig /all to find my laptop's own IP and default gateway, arp -a to check locally cached device info, and tracert 8.8.8.8 to map every hop from my machine out to Google's public DNS server. The trace showed my laptop reaching the campus gateway, then Algonquin's own border router, then eight hops that didn't reply to the trace (routers configured to silently drop ICMP probes rather than respond — normal behavior, not a broken path), before successfully reaching the destination. Built a hop-by-hop diagram of the full path from the trace output.

ipconfig arp -a tracert ICMP
